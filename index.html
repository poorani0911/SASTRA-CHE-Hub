How to add or remove files

Since files are read live from Google Drive, manage them directly there:

➕ To ADD a file:
Open the Drive folder → go to the right subfolder (e.g. "Lecture Notes") → drag and drop your PDF → it appears on the site within seconds after refreshing.
🗑️ To REMOVE a file:
Open the Drive folder → find the file → right-click → Move to Trash. It disappears from the site after refreshing.
